# Palette UX & Accessibility Journal

## 2025-05-18 - Live Voice Assistant A11y Status
**Learning:** Animated canvas or motion components representing active AI voice state must include `role="status"` and `aria-live="polite"` so screen readers can announce when recording/listening mode activates.
**Action:** Always add accessible status regions and descriptive `aria-label`s to animated voice assistant orbs.
